# Индекс документации

Документация проекта ведётся на русском языке. Это единственная точка входа:
каждый документ отвечает за свою область, факты между файлами не дублируются.
Карта отвечает только на вопрос «в каком файле искать».

## Каноны

| Файл | Назначение |
|---|---|
| `../AGENTS.md` | Канон для AI-агентов: стек, команды, структура, workflow, критические инварианты |
| `../README.md` | Описание продукта и запуск: что за сервис, как поднять, как устроены ветки |
| `prd.md` | Бизнес-требования: задача, границы, юзеркейсы, функции Core и изменяемые, риски |
| `architecture.md` | Технические решения: модель состояния, сущности, процессы, псевдокод, логирование, инварианты |
| `contracts.md` | Внешние вызовы и их ограничения: Telegram, OpenRouter, GitHub |
| `llm.md` | Контракты LLM, проверки Go над выводом модели, промты и файлы правил |
| `backlog.md` | Этапы, активные задачи и осознанно отложенное |
| `state.md` | Короткий снимок: прод, что в работе, что дальше, риски и открытые вопросы |
| `../CHANGELOG.md` | Летопись версий, анонсы релизов и решения владельца |

## Спеки и паспорта

| Каталог | Назначение |
|---|---|
| `plans/plan-<slug>.md` | Спека нетривиального среза до реализации; у закрытого среза остаётся выжимка «что вышло иначе и почему» |
| `specs/<функция>.md` | Глобальная спека функции |
| `acceptance/<slug>.md` | Паспорт приёмки среза: что меняется для людей, что проверено, как повторить проверку |

Правило жизни спеки и паспорта - `../AGENTS.md`, раздел «Workflow».

## Что не в карте

- `.claude/CLAUDE.md` - симлинк на `../AGENTS.md`, своего содержания нет.
- `src/internal/app/prompts/*.md` - рабочие промты модели, часть кода, а не
  документация; что они обязаны вернуть и когда вызываются - [llm.md](llm.md).

## Правило

Не дублировать детальные факты между файлами. Волатильное - версия, ревизия,
проверка живости - живёт только в `state.md`; устойчивый факт кладём в
профильный документ и ссылаемся на него.
