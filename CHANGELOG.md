# Changelog

Формат Keep a Changelog. Решения владельца и архитектурные - строками «Решение:»,
при свёртке старых версий они сохраняются. Версионный раздел начинается секцией
`### Анонс` - текстом для канала заказчика по правилам скилла `announce`.

## [Unreleased]

## [0.2.4] - 2026-10-07

Служебный релиз без видимых клубу изменений: анонса нет. Автор бота заводит тикет как
раньше; новое видит команда разработки - тикет сразу на доске Galera.

### Добавлено

- Новый тикет из бота сразу появляется карточкой на доске Galera, оставаясь в
  репозитории проекта. Переменная `GITHUB_BOARD_ID`, токену нужно право организации
  Projects: read and write. Сбой доски публикацию не останавливает (galera-tasks#102).

### Изменено

- Репозиторий и проекты переехали в организацию galera-club: путь модуля, образ
  `ghcr.io/galera-club/tg-intake`, владелец проектов в базе - миграцией 0013
  (galera-tasks#102).

- Проверки по общим правилам Galera: `make ci-check` гоняет govulncheck и gitleaks, линтер с
  gosec, без тестовой базы падает. Платные `eval` и `live` стартуют только с `PAID_OK=1` и
  останавливаются на потолке `MAX_CALLS`. CI по кнопке зовёт `make ci-check`. Модель в шагах
  диалога - за интерфейсом `Completer`. Go 1.25.13 с фиксами stdlib. Поведение бота не
  менялось, анонса нет (galera-tasks#137).

## [0.2.3] - 2026-09-28

Служебный релиз без видимых клубу изменений: анонса нет. Уведомления владельцу идут
как раньше, тема включится отдельно после переключения на бота тревог (galera-tasks#70).

### Добавлено

- Переменная `ALERT_THREAD_ID`: тема группы уведомлений владельцу
  (`message_thread_id` Bot API). Пусто - без темы, запрос как до релиза; кривое
  значение останавливает старт, как у `ALERT_CHAT_ID`. Тема ставится только
  уведомлениям в чат из конфига: работа в прежний чат и сообщения автору темы не
  получают. В логе старта `alerts_enabled` поле `thread_id`.
- Compose: `ALERT_THREAD_ID: ${ALERT_THREAD_ID:-}`, переменная контура заводится пустой.

## [0.2.2] - 2026-09-27

Технический релиз после аварии 27.09: анонса нет, код 0.2.1.

### Исправлено

- Compose: режим tmpfs `/tmp/intake` задан явно (`mode: 1023`, это 01777). Без него права
  1777 были только на первом старте контейнера; после перезагрузки узла A 27.09 в 03:00
  tmpfs получил 755, бот падал на `media_failed` и лежал 4,5 часа.

## [0.2.1] - 2026-09-22

Технический релиз под переезд прода на узел A (galera-tasks#9): анонса нет, код 0.2.0.

### Изменено

- Compose без пина `api.telegram.org`: с узла A Telegram отвечает напрямую.
- `deploy/safe-ssh.sh`: хост только из `INTAKE_SSH_HOST` (адреса узлов в публичный
  репозиторий не попадают), ресурс по умолчанию `intake`, действие `db-dump` - дамп базы
  потоком в файл оператора.
